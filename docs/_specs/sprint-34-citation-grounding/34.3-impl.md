# Sprint 34.3 — Implementation Notes & QA Report

Citation grounding, markdown-aware + cross-chunk. Spec: [`34.3-spec.md`](34.3-spec.md). Scope chosen by
user: **E.1 + E.2** (E.3 graceful degradation deferred).

## What was completed

All in [`src/lib/tools/lease-tools.ts`](../../../src/lib/tools/lease-tools.ts) `validateGrading`. No
route/API/UI/prompt changes; no new deps.

- **E.1 — markdown-emphasis-aware grounding match.** New `normaliseForGrounding(s)` (lowercase + strip
  `*`/`_`/`` ` `` + collapse whitespace), applied to **both** the chunk body and each citation part.
  Recovers citations the corpus emphasises inconsistently — the observed reject was the body holding
  `*Marini v. Ireland*, 56 N.J. 130 (1970)` (italic markers mid-citation breaking the verbatim
  `includes`). Stripping only removes chars, so only genuinely-present-modulo-formatting citations newly
  pass.
- **E.2 — cross-chunk body match + re-point.** The A.2 loop now scans the **cited chunk first, then every
  other retrieved chunk** (`RETRIEVAL_K = 4`); a citation verbatim in any of them is grounded in the
  context the model was shown. On a cross-chunk hit, `chunk_id` is re-pointed to where the evidence lives.
  A `needle &&` guard prevents an emphasis-only part normalising to `''` from false-matching.
- **P3c boundary preserved.** A citation in **no** retrieved chunk (even after stripping) still throws
  `citation_not_in_body`. Behaviour-preserving for every 34.1/34.2 acceptance.

## Carry into next sprint

- **Retrieval recall:** if an authority lives only in a chunk that was never retrieved (outside K=4),
  neither E.1 nor E.2 helps — that's a retrieval-quality lever (raise K / better ranking), a separate,
  larger concern.
- **Corpus emphasis consistency (orthogonal, optional):** the corpus bolds citations inconsistently
  (`**whole**` vs `*name*,`). E.1 makes the validator robust to it, so no corpus rewrite is required;
  standardising emphasis would be defensible hygiene (ties to the corpus-provenance idea).
- **Non-determinism:** 0 ungraded reflects this lease + these runs, not a guaranteed floor.
