# Sprint 34.2 — Implementation Notes & QA Report

Citation-grounding follow-up: recover the two **chunk-identity** citation forms Lever A.1 missed, while
keeping ungrounded external-authority citations rejected. Spec: [`34.2-spec.md`](34.2-spec.md).

## What was completed

All in [`src/lib/tools/lease-tools.ts`](../../../src/lib/tools/lease-tools.ts) (`validateGrading` +
helpers). No route/API/UI/prompt changes; no new deps.

- **Lever D.1 — embedded chunk pointer.** Generalised A.1 from `raw.statute_citation === raw.chunk_id`
  to `raw.statute_citation.includes(raw.chunk_id)`, so a pointer wrapped in a label
  (`"Early Termination — early-termination-general#section:1"`) is recognised as the already-validated
  chunk reference and canonicalised via `humaniseChunkPointer`. Exact match is a subset → behaviour-
  preserving for 34.1.
- **Lever D.2 — de-slugged chunk title.** New `chunkSlugWords()` (factored out of `humaniseChunkPointer`)
  + `normaliseCitation()`; accept when `normaliseCitation(citation) === normaliseCitation(slug words)`
  (e.g. `"Attorneys' Fees Clauses"` ≡ `attorneys-fees-clauses`), canonicalised to the humanised label.
  **Exact** normalised equality only — partial/looser matches fall through to rejection.
- **Lever D.3 — em-dash label+statute concatenation** (folded in after live verify surfaced it). Extended
  A.2's split delimiters from `;`/`&`/`and` to also split on a whitespace-bounded dash (`—`/`–`/` - `),
  so `"Late Fees on Rent — NJSA 56:8-1 et seq."` isolates the grounded statute part already in the body.
  One-line regex widening; whitespace-on-both-sides leaves intra-token hyphens (`NJSA 56:8-1`) untouched.
- **P3 boundary preserved.** A citation that is neither the chunk's identity nor in its body still
  throws `citation_not_in_body`. No lever was added for it (load-bearing for source-grounding).
- Gate order: retrieved-check → D.1 (includes) → A.2+D.3 (verbatim body part, dash-aware split) → D.2 (title) → reject.

## P4 → folded in as D.3

The live run's single remaining reject was a **4th** pattern (P4): `"Late Fees on Rent — NJSA 56:8-1 et
seq."` against `late-fees-general#section:5`, where `"NJSA 56:8-1 et seq."` IS verbatim in the body but
the **em-dash** join blocked A.2's split. Per user direction this was folded into 34.2 as **Lever D.3**
(a ~1-line delimiter widening, same A.2 intent) rather than deferred — see "What was completed" and the
D.3 test above. Deterministically reproduced by the D.3 unit test (the test's citation string is the
exact one from the log).

D.3 was **not** re-scanned live: it's a delimiter-only change with a deterministic unit test that
replays the exact logged citation, and the prior live run already exercised the full grading path. A
fresh ~52s scan would only non-deterministically maybe-reproduce P4, adding no confidence over the test.
