replace the verbose `scan-narrative` summary with a deterministic minimal receipt (A4). Spec:
[`33.A.2-spec.md`](33.A.2-spec.md). Methodology: spec → TDD red→green → gates → live verify → QA.

## What was completed

### A3 — gate ScanTimeline off the auto-scan turn (Tenant only)

- Added `isAutoScanTurn?: boolean` to `ChatMessageProps`
  ([ChatMessage.tsx](../../../src/components/chat/ChatMessage.tsx)). The `ToolInvocationsBlock` gate
  became `showTimeline = isTenant && scanInvocations.length > 0 && !isAutoScanTurn`, and on a Tenant
  auto-scan turn it now suppresses **both** the timeline **and** the raw scan-tool-card fallback
  (`suppressScanCards`) so no developer trace leaks into the tenant view. Non-scan deliverables
  (`NegotiationEmailCard`) and Reviewer/Admin trace are unaffected.
- New pure helper `markAutoScanTurn(messages)`
  ([auto-scan-turn.ts](../../../src/components/chat/auto-scan-turn.ts)) marks the **first scan-bearing
  assistant message** as the auto-scan turn, reusing the exported `SCAN_TOOL_NAMES`. `ChatUI` threads
  the annotated array into `ChatTranscript` (survives `mergeSyntheticMessages` + the `{...msg}` spread).

### A4 — deterministic minimal receipt replaces the verbose summary

- `buildSummary` ([scan-narrative.ts](../../../src/components/lease/scan-narrative.ts)) now emits, for
  `scan-complete` and `scan-partial`:
  `Scan complete. {N} findings on the right — ask me about any of them.` — **N = red-flag count
  (`tally.total` = high+medium+low)**, matching the right-pane verdict + count strip. The per-severity
  tally and clause-category enumeration are gone (the right pane owns them). The `scan-fatal` copy +
  `SCAN_FATAL_PROMPTS` are unchanged; source routing + follow-up chips are preserved.
- Removed the now-dead `topClauseCategories` / `joinCategories` helpers + the `CLAUSE_TYPE_LABEL` import.
- `ChatTranscript` ([ChatTranscript.tsx](../../../src/components/chat/ChatTranscript.tsx)) scopes the
  `SUBSTANTIVE_REPLY_MIN_CHARS` heuristic to `scan-fatal` only (see D4 below); the streaming guard stays.

**Two TDD-discovered refinements (the honest drift):**

1. **A3 discriminator changed from `autoScanConversationId` → "first scan-bearing assistant message."**
   The spec proposed matching the auto-scan turn via `autoScanConversationId`. **Live verify proved that
   mechanism is a no-op in real usage:** `AutoScanRunner` is silent (it only `appendToolEvent`s + sets
   `autoScanConversationId`; it never populates `ChatUI.messages`). So the timeline only renders in the
   chat on a **reloaded, SSR-hydrated** conversation — exactly when `autoScanConversationId` is `null`.
   The spec explicitly allowed "compute from message position … whichever is cleaner during TDD"; the
   position-based discriminator is correct and survives reload. This is the headline catch of the live
   pass — the unit tests were green while the wiring did nothing.
2. **D4 refined: the heuristic is scoped to `scan-fatal`, not fully retired.** Reading the S20.7 tests
   showed `SUBSTANTIVE_REPLY_MIN_CHARS` also serves an anti-contradiction role (model claims success ↔
   synthetic "I had trouble"). The minimal complete/partial receipt can't contradict the cards, so it
   always renders; the fatal copy keeps the S20.7 guard. Net: S20.7/S20.8 tests stayed green, no
   reintroduced bug, and the receipt still renders for short acks (the original drift vector).

## Carry into next sprint

- **Auto-scan disabled (env) edge:** if `LEASELENS_AUTO_SCAN_ENABLED=false`, a user's *first* manual
  scan would be treated as the auto-scan turn and have its timeline suppressed. Auto-scan is on by
  default, so this is a benign edge; revisit only if the env flag ships off.
- **Multi-tier receipt N vs verdict N:** the receipt counts all red flags; `computeScanVerdict`'s
  headline counts the top tier only. They coincide on the sample (13/13); a multi-tier lease could read
  differently on the two surfaces. Both are deterministic and card-grounded — flagged in spec QA, a
  33.B framing question, out of scope here.
- Vestigial `clause_type` collection in `scan-narrative.ts` (no longer read after categories removed) —
  harmless; prune in a future tidy if touching that file.
