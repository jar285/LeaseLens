# Security Deposit Return

## 30-day return deadline

A New Jersey landlord must return the tenant's security deposit, **with interest** (see security-deposit-interest), within **30 days after the tenant vacates** the premises.

The deadline is set by **NJ Stat 46:8-21.1** ("Return of security deposit").

## Itemized accounting required

If the landlord withholds any portion of the deposit, the landlord must return the remaining balance along with a **written, itemized list of deductions** within the same 30-day window. The list must specify each deduction by category and amount.

A bald "withheld for damages" letter without itemization does not satisfy the statute.

## Permitted deductions

The landlord may deduct from the security deposit only for:

- Unpaid rent.
- Damage beyond ordinary wear and tear.
- Other actual losses caused by the tenant's breach of the lease.

Routine cleaning, ordinary wear, painting between tenancies, and similar landlord-side maintenance costs are **not** deductible.

## Doubling penalty

If the landlord fails to return the deposit (or the unwithheld balance) within 30 days, the tenant may sue and recover **double the amount wrongfully withheld**, plus court costs and reasonable attorneys' fees.

## Common red flags

- Lease language that gives the landlord more than 30 days to return the deposit.
- Lease clauses that purport to make the deposit "non-refundable."
- Blanket "deducted for cleaning" deductions without itemization.
- A lease that disclaims the doubling penalty under NJ Stat 46:8-21.1 — that disclaimer is unenforceable.
