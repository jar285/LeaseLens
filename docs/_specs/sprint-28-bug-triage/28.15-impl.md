     `cancelReplace()` (just closes). Local `confirmOpen` boolean only — no new context state.

   is autogenerated by `next dev`/`next build`; its only diff was the dev-vs-prod routes-types import
   path churning every run. The file stays on disk (build still finds it) and no longer dirties
   `git status`.

No change to the destructive sequence semantics; no new deps; no prompt/route/API changes.

## Follow-up — calm, symmetric enter + exit motion (post-review polish)

User feedback: the dialog *popped in* instantly (then: make the dismiss ease out the same way). Root
cause: a native `<dialog>` jumps from `display:none` on `showModal()` **and to `display:none` on
`close()`**, so neither direction animates with a plain transition. Style direction was decided against
trends: per [ui-ux-design-philosophy.md](../../_architecture/ui-ux-design-philosophy.md)
(§Healthcare/Finance/Legal → *avoid heavy playful visuals + low-contrast glass*) and power-words'
Dieter Rams (*"avoid unnecessary glass effects"*), **no claymorphism / glassmorphism** — the panel
stays the opaque conservative-Material surface. The fix is **motion, not material**: a calm fade +
subtle scale, both directions (user-chosen, ~150ms ease-out).

- **Technique:** the fade+scale lives on the **dialog element** with `transition-discrete`
  (`transition-behavior: allow-discrete`) so the discrete `display`/`overlay` flip is **deferred until
  the opacity+scale transition finishes** — that's what makes `close()` ease OUT instead of popping.
  `starting:open:*` seeds the enter; `open:*` are the settled values; `::backdrop` fades with it. All
  no-op under `motion-reduce:`. Pure CSS, **zero deps, zero new state, no timers** — `dialog.close()`
  is still called synchronously and `role` clears on `open=false`, so tests stay synchronous.
- **Panel always mounted** (no `{open ? … : null}`): the leave needs content to show while the dialog
  fades; visibility + a11y are gated by `[open]`/`role`, not by unmounting.
- **Tests:** the motion test now pins the symmetric contract on the dialog (`transition`,
  `transition-discrete`, `open:opacity-100`, `open:scale-100`, `starting:open:opacity-0`,
  `starting:open:scale-95`); suite **1139**.
- **CSS emission proof:** `allow-discrete` + `open\:opacity-100` + `open\:scale-100` +
  `starting\:open\:opacity-0/scale-95` + `open\:backdrop` + `starting\:open\:backdrop` all present in
  the compiled `.next` CSS — real, not inert.
- **Live exit proof (Playwright frame sampling during Cancel):** after dismiss, `[open]`→false and
  `role`→null immediately, but `display` **stays `block`** while `opacity` eases `1.00 → 0.67 → 0.07`
  over ~150ms (allow-discrete deferring `display:none`), then hides. Enter previously verified
  (`transition-duration 0.15s`, `cubic-bezier(0,0,.2,1)`). Gates re-run: lint/typecheck/test/build green.
